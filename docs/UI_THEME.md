# LogScope UI theme

Two themes are implemented via CSS custom properties in `apps/playground/src/studio.css`.

Dark: background `#0d0e14`, surface `#161723`, secondary `#1e1e2d`, accent `#8e80ff`, accent blue `#5d8bff`.
Light: background `#f7f7fc`, surface `#ffffff`, secondary `#f1effb`, accent `#6757db`, accent blue `#4f72df`.

The dashboard has three top-level modes (Live Logs, Compare, Replay) and contextual dialogs (Connect API, Fields, Settings). System font stacks avoid redistributing proprietary fonts.
